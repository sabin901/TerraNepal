# TerraRaksha engine implementation — 15 November 2026

## Completed in this implementation

- Append-only private case ledger with revision, action and evidence-backed outcome
  records; chronological replay; attributed review status; content hashes and
  tamper-detection checks. No external authenticity or reviewer endorsement inferred.
- Regional Polygon/MultiPolygon–Point exposure analysis, holes and boundary rules,
  input lineage, time filtering, bounded geometry and no damage/safety inference.
  Observed footprints cannot describe periods after acquisition. Future carry-forward
  requires an explicit scenario. No hazard footprint is generated by this engine.
- Authenticated private case/exposure APIs and a browser workspace with readable
  case summaries, imports, replay, integrity verification and downloadable reports.
- Verified backups include the case ledger and check its hash chain on restore.
- Private importer connects published weather snapshots to actual dated review cases.
  Seven city cases were imported locally; they remain unverified forecast evidence,
  not disaster incidents. No operational actions or impacts were invented.
- Direct GFS acquisition, native GRIB decoding, immutable evidence and exact replay;
  a real six-request bounded trial succeeded. Overlapping accumulation intervals
  remain separate. Optional decoder is outside the public Pages dependency stack.
- Initial archive loading no longer blocks the independent case workspace.

## What this closes and what it does not

This implements the missing case and exposure software foundations and the first
commercial-source experiment. It does not complete independent Nepal forecast skill,
calibrated flood/landslide models, nationwide verified exposure inventories, approved
sector thresholds/actions, bilingual field-user validation, independent delivery
monitoring, or a commercial data migration. No company/operational warning launch
is implied. The user-selected GitHub-only public research scope stays unchanged.

The local workflow is available at `/workspace.html` on the private backend. GitHub
Pages publishes only allowlisted public weather/evidence artifacts. Private cases,
actor names, imported asset inventories and input GeoJSON are not copied to Pages.

tests, 36 JavaScript assertions, workspace JavaScript syntax, and the optional
direct-weather dependency vulnerability audit. Container verification also checks
case-import dependencies, authenticated workspace access and ledger integrity.
